# Prototype 版本紀錄

此文件記錄每一個正式保存、可供回看與分享的 prototype。日常小修改仍由 Git commit 保存，不需要全部列在這裡。

## prototype-v0.1 — 2026-09-13

### 測試目標

驗證固定節日順序、每回合四個選項、禮物隨機結果，以及婚戒出現頻率的整體感受。

### 已包含

- 五年共 14 個固定順序事件。
- 每個事件顯示四個禮物選項。
- 一般事件從一般禮物清單隨機抽取，單一回合不重複。
- 東京出差任務只使用四個東京專屬選項，顯示順序隨機。
- 一般事件每兩次為一組，每組恰好一次出現婚戒。
- 可以重抽當前事件；是否出現婚戒不會因重抽而改變。
- 可以選擇禮物、前往下一事件、查看整輪紀錄及重新開始。
- 支援手機與桌面版面。

### 尚未包含

- 禮物分數與好感度。
- 角色反應與劇情文字。
- 分手或多重結局判定。
- 音效與完整視覺素材。
- GA4 分析事件。
- 玩家進度保存。
